# @webship.co/workspace-svelte

Svelte for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that makes a SvelteKit
app with the official create flow and serves it from a container of its own (the app's Node.js in the app's
container, the Node adapter), the Svelte step pack wired into the workspace's testing setup of that app, and its AI
items. The workspace is container-based (DDEV by default).

The builder, the tests and CI come with the first release, `1.0.0`.
